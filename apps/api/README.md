# KARTA API

NestJS backend for KARTA Alpha 0.1.

## Responsibilities

- Authentication and authorization
- User and identity-profile management
- Document metadata
- Sharing and verification workflows
- Audit logging
- Secure integration with PostgreSQL and object storage

## Security

Never place production secrets in source control. Use environment variables locally and a managed secrets system in production.

The API must never log passport numbers, national ID numbers, document images, access tokens, passwords, PINs, or other sensitive identity data.
