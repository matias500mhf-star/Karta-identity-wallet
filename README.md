# KARTA Identity Wallet

KARTA is a secure identity and personal-document wallet focused on local-first storage, controlled sharing, backup, QR workflows and privacy-preserving access.

## Project status

KARTA is under active development. Current release-candidate work is based on the Alpha 0.9 stabilization branch and is not yet a production identity credential or a substitute for official government-issued documents.
